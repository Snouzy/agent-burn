---
title: Environment Variables
description: Override local data-directory detection.
icon: Variable
---

Agent Burn inherits the local data-directory detection from the upstream readers.

Common variables:

| Variable | Purpose |
| --- | --- |
| `CLAUDE_CONFIG_DIR` | Override Claude Code config/log root |
| `CODEX_HOME` | Override Codex home directory |
| `CURSOR_DATA_DIR` | Override Cursor application-support directory or `state.vscdb` |
| `CURSOR_ACCESS_TOKEN` | Override the Cursor session token used for usage fetch |
| `KIMI_DATA_DIR` | Comma-separated Kimi data roots that replace both `~/.kimi` and the Kimi Code home; each root may hold either layout |
| `KIMI_CODE_HOME` | Override the Kimi Code home directory (default `~/.kimi-code`), used for sessions when `KIMI_DATA_DIR` is unset and for live-quota credentials |
| `KIMI_CODE_BASE_URL` | Override the Kimi Code API base URL used for the live quota request |
| `LOG_LEVEL=0` | Silence progress output in automation |

Example:

```bash
CODEX_HOME=/tmp/codex agent-burn harness codex --json
CLAUDE_CONFIG_DIR=/tmp/claude agent-burn harness claude --offline
KIMI_DATA_DIR=/tmp/kimi agent-burn harness kimi --offline
```
